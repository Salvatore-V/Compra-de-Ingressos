# 🎟️ Compra de Ingressos

Aplicação web interativa desenvolvida durante os cursos de lógica de programação e JavaScript da Alura. O projeto simula um sistema de bilheteria online onde o usuário pode selecionar o tipo de ingresso desejado (pista, superior ou inferior) e a quantidade, atualizando instantaneamente a quantidade de ingressos disponíveis em estoque.

---

## 🚀 Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**

---

## 🛠️ Funcionalidades

* **Seleção de Categoria**: Escolha entre diferentes tipos de ingressos disponíveis (Pista, Cadeira Superior, Cadeira Inferior).
* **Controle de Quantidade**: Defina o número de ingressos que deseja adquirir.
* **Validação de Estoque**: Verifica se há quantidade suficiente disponível para a compra e desconta do total de forma dinâmica.
* **Manipulação do DOM**: Atualização em tempo real dos valores exibidos na interface da página.
